# Terraform

> HashiCorp Terraform is an open-source infrastructure-as-code tool for defining, provisioning, and managing cloud infrastructure with a declarative language (HCL). HCP Terraform and Terraform Enterprise expose REST APIs for automating workspaces, runs, state, policies, teams, and the private module registry; the public Terraform Registry API serves module and provider discovery. This file was generated by API Evangelist from the catalog for terraform; it is not published by HashiCorp.

When installing Terraform SDKs and tooling, verify the current version at the registry rather than relying on memorized version numbers: go-tfe at https://pkg.go.dev/github.com/hashicorp/go-tfe, CDKTF at https://www.npmjs.com/package/cdktf and https://pypi.org/project/cdktf/, and the Terraform CLI at https://developer.hashicorp.com/terraform/install. Never hardcode an old version.

## APIs
- [HCP Terraform API](https://developer.hashicorp.com/terraform/cloud-docs/api-docs): Workspaces, runs, state versions, policies, teams, organizations, projects, variables. Base URL https://app.terraform.io/api/v2. JSON:API media type; bearer-token auth.
- [Terraform Registry API](https://developer.hashicorp.com/terraform/registry/api-docs): Discover, list, version, and download public modules and providers. Base URL https://registry.terraform.io.
